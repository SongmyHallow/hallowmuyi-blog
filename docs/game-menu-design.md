# 首页游戏主菜单化设计文档

> 状态：已实施（全中文 RPG 菜单、PRESS START 闪烁 + HP/EXP 状态条均保留） · v1 · 2026-11-10
> 范围：首页重构 + 文章列表页标题调整。色板、字体、组件体系沿用 pixel-design.md，不新增颜色。

---

## 一、目标

当前首页是「PLAYER 1 卡片 + 文章卡片列表」，像素皮肤有了，但**结构还是博客**。本次把首页结构改成经典 RPG 主菜单：

```
标题画面 → 角色状态 → 主菜单 → 任务日志
```

原则不变：克制、可读、无图片纯 CSS/HTML、移动端可用。

---

## 二、首页结构（从上到下）

```
┌────────────────────────────────┐
│  MUYI BLOG                     │   标题画面：36px 像素字
│  PRESS START ▮                 │   12px，光标块 steps() 闪烁
├────────────────────────────────┤
│  PLAYER STATUS          LV.01  │   角色状态面板
│  MUYI                          │
│  HP  ▮▮▮▮▮▮▮▯  7/8             │
│  EXP ▮▮▯▯▯▯▯▯  25%             │
│  CLASS: 写作者                  │
├────────────────────────────────┤
│  MAIN MENU                     │   主菜单（核心改动）
│  ▸ 开始冒险          文章列表   │
│    读取存档          归档       │
│    物品栏            标签       │
│    制作名单          关于       │
├────────────────────────────────┤
│  QUEST LOG                     │   任务日志（最新 5 篇）
│  ▸ 博客开张          [11-09]   │
│  ▸ …                           │
│  VIEW ALL QUESTS →             │
└────────────────────────────────┘
```

### 2.1 标题画面

- `MUYI BLOG` 36px 像素字 + 小色块（沿用现有站名样式，放大）
- `PRESS START ▮`：末尾方块用 `steps(2, jump-none)` 做 1s 闪烁，尊重 `prefers-reduced-motion`（命中则常亮不闪）

### 2.2 PLAYER STATUS 面板

在现有存档卡基础上加两条**纯装饰**状态条（CSS 宽度，无 JS）：

- `HP ▮▮▮▮▮▮▮▯ 7/8` —— 固定值，趣味文案
- `EXP ▮▮▯▯▯▯▯▯ 25%` —— 可以做成**真实的**：按「今年已发文章数 ÷ 年度目标 12 篇」在构建时计算， Astro 构建期取集合长度即可，零运行时成本
- `CLASS: 写作者` 一行职业文案

### 2.3 MAIN MENU（核心）

- 4 行菜单项，每行：**24px 像素中文名**（左）+ 12px 灰色小字说明（右，桌面端显示，移动端隐藏）
- 交互：默认无 ▸；hover / 键盘 focus 时左侧出现 `▸`（accent 色），整行反色为 accent 底
- 就是导航那 4 个页面（/blog /archive /tags /about），**不新增路由**
- 顶部导航栏保留不动（菜单只在首页）

### 2.4 QUEST LOG（最新文章）

- 不再用大卡片，改成**紧凑任务行**：`▸ 标题`（16px 正文像素化？不——标题 24px 像素字太大，任务行用 **16px 系统字体**保持可读，`▸` 用 accent 像素符号）
- 右侧 `[MM-DD]` 12px 像素字日期
- hover 整行反色
- 最多 5 条，底部 `VIEW ALL QUESTS →`（px-btn）链到 /blog

---

## 三、文章列表页（/blog）配套微调

只改两处，卡片本身不动：

- 页标题 `全部文章` → `SELECT SAVE`（副标题保留 `TOTAL n`）
- 其余页面（归档/标签/关于/详情）**不动**，阅读体验优先

---

## 四、技术要点

| 项 | 做法 |
|---|---|
| 闪烁光标 | `@keyframes blink { 50% { opacity: 0 } }` + `animation: blink 1s steps(2, jump-none) infinite`；`@media (prefers-reduced-motion: reduce)` 中禁用 |
| EXP 真实进度 | `getCollection('blog')` 统计今年非草稿数，`Math.min(count/12, 1)` 算宽度 |
| 菜单 ▸ 选择器 | CSS `::before` 默认透明，`:hover`/`:focus-visible` 显示，无 JS |
| 字体 | 全部沿用 Fusion Pixel 12px，字号 12/24/36 |
| 颜色 | 不新增，沿用现有色板 |

---

## 五、不做的事

- 不做键盘上下键选菜单（鼠标/触屏已够用，JS 收益低）
- 不加音效、不加背景音乐
- 不改文章详情页、不动后台
- 导航栏不改（首页菜单是页面内容，不是导航替代品）

## 六、验收

1. build 通过；首页首屏完整呈现 4 个区块

3. 深浅模式下反色 hover 都清晰
4. `prefers-reduced-motion` 下 PRESS START 常亮
5. 菜单 4 项链接正确，键盘 Tab 可聚焦且有焦点样式
