## 1. 信息架构

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 首页 | hero + 最新文章列表（已有，需打磨） |
| `/blog` | 全部文章 | 按时间倒序，带摘要（已有，需打磨） |
| `/blog/[slug]` | 文章详情 | 已有，需补充元信息与导航 |
| `/archive` | 归档 | **新增**，按年份分组列出全部文章 |
| `/tags` | 标签索引 | **新增**，标签云（标签 + 文章数） |
| `/tags/[tag]` | 标签详情 | **新增**，该标签下文章列表 |
| `/about` | 关于 | 已有，文案待定 |

导航栏：`hallowmuyi`（回首页） | 文章 · 归档 · 标签 · 关于 | 主题切换

**决策点 1：是否引入「分类（category）」？**
lapis.cafe 有 category + tag 两层（分类如"深度学习"，标签如"模型考古学"）。
- 方案 a：只保留 tags（现状），简单，适合文章量少的时候
- 方案 b：加 category 字段（每篇文章恰好一个分类），信息架构更接近参考站，归档页可按分类分面

建议：先用 a，文章过 30 篇再考虑 b。标签页已能满足归类需求。

## 2. 视觉系统（基于现有 global.css 微调）

### 色板（保持现状）
- 亮色：背景 `#fbfaf8` / 正文 `#292524` / 次要 `#78716b` / 强调 `#7c5c3e` / 边框 `#e7e2dc`
- 暗色：背景 `#141312` / 正文 `#e7e5e4` / 次要 `#a8a29e` / 强调 `#d4a373` / 边框 `#2a2725`

### 字体
- 标题：`Noto Serif SC`（衬线，已有）
- 正文：系统字体栈（现有）；**拟改为正文也用衬线**（lapis.cafe 正文为衬线，中文阅读感更好）——决策点 2
- 日期/元信息：`Geist Mono` 等宽

### 排版参数
- 容器宽度：`max-w-2xl`（672px）现状；文章详情可收窄到 `42rem` 保持行长舒适
- 正文：15–16px / 行高 1.9（现状）；段间距 1rem
- 文章标题：2xl→3xl；h2/h3 样式已有
- 分隔与留白：列表项间距、区块间距统一走 4 的倍数

### 深色模式
- 切换已实现（localStorage + prefers-color-scheme，无闪烁脚本）
- P2 验收：切换瞬间无白闪；刷新后主题保持

## 3. 各页面设计

### 3.1 首页
- Hero：名字 + 一句签名（lapis 风格："理解以真实为本…" 这类一句引言）
- 可选外链区（GitHub / 邮箱等 icon 链接）——决策点 3
- 最新文章 5–8 篇，每篇一行卡片：
  - 标题（衬线，hover 变色）
  - 日期（等宽，右侧）
  - 摘要一行（次要色，可选）
  - 标签 chips
- 底部"全部文章 →"

### 3.2 文章列表 `/blog`
- 按年份分组（2026 ▾）或直接平铺——lapis 是平铺+分页
- 条目同首页卡片；文章多后加分页（P2 暂不做，>20 篇再说）

### 3.3 文章详情 `/blog/[slug]`
- 头部：标题 / 日期 / 标签 / **字数 + 预计阅读时长**（lapis 有，"1017 字 | 5 分钟"）
- 正文：`.prose-blog` 已有基础，补充：
  - 表格样式、脚注样式
  - 代码块 macOS 风格（圆角 + 红绿灯点可选）
  - 标题锚点链接（hover 显示 #）
- 底部：上一篇 / 下一篇导航
- 可选：右侧 TOC 目录（桌面宽屏显示，移动端隐藏）——文章普遍不长，建议 **P2 不做**

### 3.4 归档 `/archive`（新增）
- 按年份倒序分组，每组内按日期列出：日期 + 标题，极简一行式

### 3.5 标签 `/tags` + `/tags/[tag]`（新增）
- `/tags`：标签列表，格式 `#标签 (n)`，按文章数排序
- `/tags/[tag]`：标题 + 该标签文章列表（复用文章卡片）

### 3.6 关于 `/about`
- 排版同文章页；文案 P5 再打磨，P2 只保证版式正确

## 4. 移动端适配
- 断点：<640px 为主
- 导航收窄：链接字号减小，间距收紧；不引入汉堡菜单（4 个链接放得下）
- 文章卡片：日期换行到标题下方（空间不足时）
- 验收：iPhone 宽度无横向滚动；触控目标 ≥ 40px
